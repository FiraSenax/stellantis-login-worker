Ergänzung für Home Assistant · Testversion

Die Integration bleibt.
Der Login läuft lokal.

Die Stellantis Vehicles HACS-Integration kümmert sich um dein Fahrzeug. Dieses kleine Add-on ersetzt ihren öffentlichen Login-Helfer durch einen Browser auf deinem eigenen Home-Assistant-Rechner.

Genau dafür gibt es dieses Projekt: die bestehende Integration nutzen, ohne die Anmeldung über einen fremden, gemeinsam genutzten Login-Dienst abzuwickeln. Die Integration wird nicht ersetzt. Auch die Fahrzeug-API wird dadurch nicht lokal.

Installation auf HA OS

  1. Die Stellantis Vehicles Integration über HACS installieren, falls sie noch fehlt.
  2. Unser Repository über den Button hinzufügen. Im App-/Add-on-Store Stellantis Login Worker installieren und starten. Der lokale Build kann mehrere Minuten dauern.
  3. Die interne Adresse aus dem Startprotokoll kopieren. Sie hat die Form http://<addon-hostname>:3000. Der tatsächliche Hostname hängt von der Installation ab.
  4. Im Loginformular der Integration diese Adresse unter Login service URL eintragen, bevor Zugangsdaten eingegeben werden. Unterstützt die Integrationsversion es bereits, lässt sich die Adresse vorher unter Neu konfigurieren → Globale Einstellungen speichern.
  5. Anmeldung abschließen und prüfen, ob die Integration geladen wird. Ein erreichbarer Helfer allein bestätigt noch keine erfolgreiche Anmeldung.

Standardmäßig wird kein Port am Host veröffentlicht. Automatische Erkennung hängt von der Integrationsversion ab; die Adresse kann auch manuell eingetragen werden.

Was sich ändert

Geht das ohne die Stellantis-Cloud?

Nein. Der öffentliche Login-Zwischendienst entfällt. Stellantis bleibt für die Kontoanmeldung, Fahrzeugdaten und Befehle erforderlich.

Ist das eine neue HACS-Integration?

Nein. Die bestehende Integration bleibt zuständig. Dieser Helfer wird als zusätzliche Home-Assistant-App installiert, weil er einen Browser im Container ausführt.

Was passiert mit meinem Passwort?

Die Integration sendet es an den eingestellten Helfer. Dessen HTTP-Handler gibt es für den laufenden Versuch an den Browser weiter und speichert es nicht in einer Konfigurationsdatei. Der Helfer hat keine eigene Zugangskontrolle; sein Port sollte intern bleiben und darf nicht ins Internet veröffentlicht werden.

Funktioniert danach jede Anmeldung?

Das lässt sich nicht versprechen. Geänderte Loginseiten, Anbieterausfälle und interaktive Prüfungen können weiter Probleme verursachen. Bei Fehlern wird nicht automatisch auf einen öffentlichen Login-Helfer gewechselt.
